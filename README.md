# Saturn 64 on Android
Saturn 64 By Llennpie https://github.com/Llennpie/Saturn

This Android port was created for a specific reason: I noticed that many fans of *Super Mario 64* wanted to make "bloopers" (machinima-style videos), but they were using mobile devices. Previously, they had to rely on emulation, which often runs very poorly—lagging significantly—on less powerful or 32-bit phones. I wanted mobile users to finally be able to experience *Saturn 64* natively, allowing them to create all the "bloopers" they had in mind. While a large portion of the code for this port was generated using AI (as I am still learning to program), every change has been reviewed and tested. I didn't want this to be another "vibecoding" project—where someone just enters a prompt like "make a port of this," without caring if it actually works or serves a purpose. I believe that if you use AI-assisted coding, you should understand what you’re doing, test every change, and genuinely care about the project. So, here is the Android port for *Saturn 64*; I hope you enjoy it. Naturally, there are still bugs that need to be fixed—after all, the experience on a mobile device is quite different from that on a PC.
